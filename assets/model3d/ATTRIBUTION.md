Rendered from `ichigo3d.glb` with `cargo run -p ume-model3d --example portrait`.

# airport.glb

Original work generated by `tools/airport/build.py` (airliners, terminal, tower, runway, hills). No third party
assets; the build script is the source. Released with the repository license. Search of CC0 packs on OpenGameArt
(aircraft models, e.g. "Jet airplane" and "Private jet" CC0) was done first, but they ship as `.blend` only, so the
scene was generated procedurally to stay GLB, tiny and reproducible.
