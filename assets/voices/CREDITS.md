# Move voices

`voices.bank` holds speech generated offline with Kokoro-82M (https://huggingface.co/hexgrad/Kokoro-82M, Apache-2.0, model weights and voice packs) through kokoro-onnx (https://github.com/thewh1teagle/kokoro-onnx, MIT). The text is each move's own name. Rebuild with `tools/voices/generate.py`.
