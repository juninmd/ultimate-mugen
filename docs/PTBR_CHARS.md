# Elenco dublado PT-BR (M.U.G.E.N)

28 personagens da comunidade com **dublagem brasileira** (falas do anime/redublagem
feitas pelos grupos *Mugen Br*, *MFmugen PT BR* e *Golden Mugen Brasil*), instalados
em `mugen/chars/` e validados no motor.

- Instalação: `C:\Users\jr_ac\AppData\Local\Programs\UltimateMUGEN\mugen\chars\`
- Volume: ~1,3 GB de personagens, dos quais **~460 MB são dados de voz** (42–203
  amostras de som por personagem, decodificadas pelo motor via `snd.rs` e tocadas
  por `audio.rs` durante o combate).
- Instalador: `scripts/fetch-ptbr-chars.ps1`
- Relatório: `scripts/verify-ptbr-chars.ps1`

## Como foi instalado

```powershell
# baixa, descompacta e instala os 28 (pula os que já existem)
powershell -ExecutionPolicy Bypass -File scripts/fetch-ptbr-chars.ps1 -SkipVerify

# validação final (uma vez, depois de instalar tudo)
cargo run --release -p ume-engine --example mugen_check -- "$env:LOCALAPPDATA\Programs\UltimateMUGEN\mugen\chars"
powershell -ExecutionPolicy Bypass -File scripts/verify-ptbr-chars.ps1
```

O script resolve o link direto do MediaFire, extrai com 7-Zip, localiza o `.def`
de personagem (`[Files]` com `cns=` e `sprite=`) e copia a pasta para
`mugen/chars/<nome>`. A origem de cada pacote (vídeo do autor) fica no catálogo do
script, para auditoria.

Depois da instalação, `scripts/tag-ptbr-names.ps1` acrescenta ` (PT-BR)` em
`name`/`displayname` do `[Info]`, para o seletor diferenciar o dublado da versão
original (há dois Raditz, dois Luffy etc. no elenco).

> Vários autores também publicam no MEGA, mas os links antigos (`mega.nz/#!...`)
> da cena BR hoje respondem `-16` (arquivo bloqueado/removido) na API pública.
> Por isso o catálogo usa apenas MediaFire; `scripts/mega-download.ps1` fica
> disponível para links MEGA válidos (download + AES-128-CTR, sem cliente externo).

## Validação no motor

| Checagem | Resultado |
|---|---|
| `mugen_check` na pasta `mugen/chars` inteira | **100 defs OK, 0 falhas** (inclui os 28 dublados; combate CPU de 60 s por personagem) |
| `sprite_audit` nos 28 dublados | todos carregam; apenas frames ausentes típicos de chars da comunidade (`(-1,-1)`), nenhum sprite em branco no corpo principal |
| `hover_check` nos 28 dublados | 24 sem flutuação; 4 com estados aéreos longos (`inumaki toge`, `mikasa`, `naofumi`, `raven` — Raven flutua por design) |
| `UME_TOUR=mugen` (Raditz × Tanjiro, Tanjiro × Gojo) | render real em jogo: retratos, HUD, hits e efeitos — `screenshots/48-ptbr-select.jpg` e `screenshots/49-ptbr-fight.jpg` |
